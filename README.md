## 📂 Repository Structure

### 1. 🩸 Mini-Project: LifePulse (Blood Donation Platform)
A specialized ASP.NET Core 9 MVC application designed to streamline urgent medical blood supply chains. 
- **Core Focus:** Enforcing complex medical business logic (ABO/Rh compatibility rules).
- **Features:** Geospatial donor matching, Hospital inventory management, and Identity-based role access.
- **Tech Stack:** ASP.NET Core MVC, Entity Framework Core, SQL Server, Bootstrap.
